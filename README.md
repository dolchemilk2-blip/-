# Nature's Care — сайт (AZ / RU / EN)

Многоязычный сайт-визитка для бренда кормов для кошек и собак.
Сделан на чистом HTML, CSS и JavaScript — **никаких программ и сборки не нужно.**

Дизайн похож на референс naturesprotection.com: природная зелёная гамма,
разделы о бренде, продукции, качестве и контактах. Названия, тексты и контакты —
условные («Nature's Care»), их легко заменить на реальные.

## Как открыть сайт у себя на компьютере

1. Скачайте все файлы проекта в одну папку.
2. Дважды кликните на файл **`index.html`** — он откроется в браузере.

Готово. Переключатель языков (AZ / RU / EN) находится в правом верхнем углу.
Выбранный язык запоминается в браузере.

## Структура файлов

```
index.html              — сама страница
css/styles.css          — оформление (цвета, шрифты, адаптив)
js/translations.js      — ВСЕ тексты на 3 языках + список продуктов
js/main.js              — логика (переключение языков, меню, табы)
assets/favicon.svg      — иконка сайта во вкладке
```

## Как изменить тексты

Откройте файл **`js/translations.js`** в любом текстовом редакторе
(подойдёт «Блокнот», но лучше — бесплатный VS Code).

Внутри три блока: `az` (азербайджанский), `ru` (русский), `en` (английский).
Найдите нужную строку и поменяйте текст в кавычках. Например:

```js
"hero.title": "Здоровое питание для вашего любимца",
```

Меняйте текст справа от двоеточия, **сами кавычки и запятую в конце не удаляйте**.
Меняйте текст во всех трёх блоках, чтобы перевод совпадал.

## Как изменить контакты

Email, телефон и адрес заданы в `index.html` (раздел «Контакты» и «Подвал»)
и в `js/translations.js` (ключ `contact.address`). Найдите `info@naturescare.az`
и `+994 00 000 00 00` и впишите настоящие данные.

## Каталог продукции

Каталог перенесён по структуре сайта Nature's Protection и находится внизу
файла `js/translations.js`:

- **`RANGES`** — линейки бренда (Lifestyle, Prime, Superior Care, Tauro Pro Line).
- **`PRODUCTS`** — товары, разделённые на `cats` (кошки) и `dogs` (собаки).
  Внутри каждого — группы: **Сухой корм, Влажный корм, Добавки, Лакомства**,
  а в группах — сами товары (всего 32 позиции).

Линейка **Superior Care** разбита по цвету шерсти (светлая / коричневая / тёмная),
как в оригинале, — беззерновые формулы против слёзных дорожек.

### Как изменить или добавить товар

Скопируйте один блок товара (`{ emoji … az … ru … en … }`), вставьте рядом
внутри нужной группы и поменяйте названия, описания и теги на трёх языках.
`emoji` — это картинка-заглушка; позже её можно заменить настоящим фото.
Названия и описания сейчас обобщённые — сверьте их с актуальным
прайсом/каталогом компании перед публикацией.

## Фотографии товаров

Реальные фото упаковок лежат в папке **`assets/products/`** (имя файла = товар,
например `dog-sc-white.jpg`). Они взяты из присланного архива каталога и уменьшены
до веб-размера (~600 px) для быстрой загрузки. Путь к фото указан у каждого товара
в `js/translations.js` (поле `img`). Если фото не загрузится, автоматически
показывается эмодзи-заглушка.

**Важно сверить:** в архиве были только фотографии (без названий, веса и цен),
файлы названы артикулами. Я подобрал фото к товарам по смыслу имён файлов, но
**соответствие «фото ↔ товар» и сами названия стоит перепроверить** по вашему
прайсу/каталогу перед публикацией. Чтобы заменить фото у товара — положите новый
файл в `assets/products/` и поправьте поле `img` в `js/translations.js`.

> Исходный архив (~200 МБ, 325 фото нескольких брендов: Nature's Protection,
> Araton, Tauro Pro Line, Misoko) в репозиторий не загружался — он слишком большой.
> На сайт сейчас вынесены товары Nature's Protection (корм, добавки, лакомства).

## Как опубликовать сайт в интернете (бесплатно)

Самый простой способ — **GitHub Pages**:
1. Файлы уже в этом репозитории.
2. В настройках репозитория на GitHub откройте раздел **Settings → Pages**.
3. В «Source» выберите ветку с сайтом и папку `/ (root)`, нажмите Save.
4. Через пару минут сайт будет доступен по ссылке вида
   `https://ваш-логин.github.io/название-репозитория/`.

Альтернативы такие же простые: **Netlify** или **Vercel** — туда можно
перетащить папку с файлами, и сайт опубликуется автоматически.
Для своего домена (например `naturescare.az`) его нужно купить у регистратора
и привязать в настройках хостинга.

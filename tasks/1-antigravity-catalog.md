# Задание 1 — Каталог (products.html). Для Antigravity, можно делить на агентов

## Контекст
Статичный сайт без сборки (HTML/CSS/JS) дистрибьютора Nature's Protection в Баку, три языка az/ru/en (тексты в `js/translations.js`, переключатель в шапке). Каталог — `products.html`, рисуется из данных функциями в `js/main.js` (секции → группы «Для кошек / Для собак» → подлинейки → карточки). Анимации — общий движок `js/spring.js` (`window.NPSpring`), стиль — плавные пружины, как сейчас на сайте.

Параллельно с тобой работают ещё две нейросети. **Меняй только эти файлы:** `products.html`, `js/main.js`, `js/motion-catalog.js`, `css/catalog.css`, `css/mobile-catalog.css`, `css/motion-catalog.css`, `css/styles.css` (только правила каталога) и новые файлы (например `css/catalog-v2.css`, `js/age-dogs.js`, `assets/age-dogs/*`). Не трогай `js/translations.js`, `js/np-official.js`, `js/catalog.js`, `js/descriptions.js`, `index.html`, `js/feed-calc.js` — их правят другие. `js/main.js` подключён и на главной — не сломай её. Не меняй `?v=N` в подключениях. Новые подписи (если нужны) добавляй объектом в своём новом JS-файле через `Object.assign(TRANSLATIONS.az/ru/en, {...})`, на всех трёх языках.

## Главная цель
Использовать место в каталоге по максимуму: не оставлять по бокам и в рядах много пустого пространства. Сейчас на широком экране каждая подлинейка (Starter, Junior, Adult…) начинается с новой строки — получается одна карточка и пустота справа (см. скриншот клиента).

## Задачи
1. **Собаки выше кошек.** В каждой секции каталога группа «Для собак» должна идти первой, «Для кошек» — второй. Сейчас они чередуются.
2. **Линейки шерсти в один ряд.** В секции Superior Care у собак три линейки — белая (White Dogs), рыжая (Red Coat), тёмная (Dark Coat). Поставь их **рядом в один ряд — тремя колонками**, товары каждой линейки идут **вниз столбиком** (компактные карточки). На телефоне (≤720px) — колонки друг под другом или горизонтальная прокрутка, без горизонтальной прокрутки всей страницы.
3. **Интерактивная «собачка возраста».** Вдоль полоски с подзаголовком возраста (где сейчас «Starter — для щенков», «Junior», «Adult», «All Life Stage») сделай горизонтальную линию, на которой стоят собачки разного возраста — **для каждого возраста своя**: щенок (Starter), подросток (Junior), взрослая (Adult), «на все возрасты» (All Life Stage). Собачки — свои SVG-иллюстрации в одном стиле, растут по мере взросления. Нажатие на собачку показывает/прокручивает к нужному разделу возраста и подсвечивает его; активная собачка выделена. Показывать только те возрасты, что есть в линейке (у белой — все четыре, у рыжей — Junior и Adult). Доступность: кнопки с `aria-label`, работают с клавиатуры; анимация нажатия и прыжка собачки — через `NPSpring`, учитывать `prefers-reduced-motion`.
4. **Плотная сетка везде.** Сетка карточек растягивается на всю ширину контейнера (auto-fill), подлинейки не рвут ряд, если в них 1–2 товара; уменьшить пустые поля по бокам на широких экранах.

## Не сломать
Окно товара (с калькулятором кормления), поиск, «Мой список» (сердечки), вкладки брендов, блок Tauro «Зачем нужны степы», плавное переключение брендов, производительность на телефоне.

## Как разделить на агентов (предложение)
- Агент A — сетка на всю ширину и «собаки первыми».
- Агент B — три линейки шерсти колонками.
- Агент C — иллюстрации собачек и интерактив.
- Агент D — проверка: ширины 375 / 768 / 1440, все три языка, без ошибок в консоли, все бренды (Nature's Protection, Araton, Tauro, Misoko).

## Готово, когда
На 1440px в рядах нет больших пустот, собаки везде выше кошек, три линейки стоят в ряд, собачки возраста кликаются и ведут к своим разделам, на телефоне всё аккуратно, ошибок в консоли нет.

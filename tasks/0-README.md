## Что кому отправить
- **Antigravity:** открыть в нём папку проекта (клон репозитория на диске D), вставить текст из `tasks/2-antigravity-data.md` и положить рядом zip со скриншотами клиента (например в `tasks/zip/`). Antigravity правит файлы прямо в папке. Это важно: `js/np-official.js` весит 1,7 МБ, чат такой файл целиком не вернёт.
- **GPT:** вставить текст из `tasks/3-gpt-home.md` и приложить 8 файлов из таблицы (строка 3) плюс 4 фото для слайдов. Попросить вернуть изменённые файлы целиком. Если GPT работает с репозиторием (Codex), достаточно дать ссылку и ветку.

## Правила для всех
- Файлы не пересекаются, поэтому результаты можно сложить в одну папку без конфликтов.
- Версии `?v=N` в подключениях никто не меняет. Их поднимет Claude одним шагом при объединении.
- Если работа идёт через git, у каждой нейросети своя ветка от `claude/natures-protection-multilingual-1vd1ni`: `task-data` (Antigravity), `task-home` (GPT).
- После объединения Claude проверит всё вместе: каталог, главную, три языка, телефон.

# Передача проекта (выжимка из облачной сессии)

**Проект:** многоязычный сайт (az/ru/en) дистрибьютора Nature's Protection в Баку — бренды Nature's Protection, Araton, Tauro Pro Line, Misoko.

## Репозиторий и хостинг
- Репозиторий `dolchemilk2-blip/-`, ветка `claude/natures-protection-multilingual-1vd1ni` (коммитить и пушить только в неё, PR не создавать).
- Сайт на GitHub Pages из этой ветки: главная https://dolchemilk2-blip.github.io/-/ · каталог …/products.html · админка …/admin/
- Общаться по-русски. GitHub-токен никогда не класть в код сайта (админка хранит его только в браузере пользователя).

## Устройство сайта
- `index.html`, `products.html`, `admin/index.html`.
- `js/main.js` — каталог (рендер частями для скорости на телефоне), окно товара.
- `js/catalog.js`, `js/translations.js`, `js/home.js`, `js/descriptions.js` — данные и тексты.
- `js/np-official.js` — официальные описания, состав, добавки, анализ, нормы и ссылка на источник для всех 125 кормов (108 NP + 17 Araton).
- `js/feed-calc.js` — калькулятор «сколько корма нужно» (ползунок везде до 10 кг; на главной, в окне товара, подсказка в каталоге).
- `js/spring.js` — движок анимаций (пружины).
- Версии файлов: `?v=N` в подключениях CSS/JS (сейчас 17, у feed-calc.js — 18). При правке — поднимать.

## Сделано на сайте
Плавные анимации, ускорение каталога на телефоне, админка для добавления товаров, контакты (адрес Ənvər Qasımzadə 56C, 11:00–20:00, Instagram, WhatsApp, иконки в шапке), калькулятор кормления, редизайн блока Tauro «Зачем нужны степы», официальные данные по всем кормам и исправления каталога.

## Промо-ролик — папка `promo/`
- `index.html` — анимация v2 (функция `renderAt(t)`), `render.js` — покадровый рендер Playwright с размытием движения, `music.py` — музыка, синтезированная в коде, `prep.py` — подготовка картинок, `media/`, `fonts/` (Onest), `audio/music.m4a`.
- Готовое видео v2 (30 с, AZ, с музыкой): `promo/promo-az.mp4` · https://dolchemilk2-blip.github.io/-/promo/promo-az.mp4
- Нужно для рендера: Node + playwright-core + Chromium, ffmpeg, Python + numpy, scipy, pedalboard, Pillow.
- Команды: кадры `node promo/render.js --stills 1,4.5`; ролик `node promo/render.js` (переменные `FFMPEG`, `CHROME`); музыка `python promo/music.py`.

## Замечания клиента к v2 (исправить в v3)
1. Фото собаки с кошкой при движении «отъезжает» — виден нижний край фото. Фото всегда должно уходить за низ кадра или растворяться.
2. У бутылок Tauro у основания остались тени от исходной съёмки.
3. Надпись «təbiət» начала уезжать, не исчезла до конца — и уже включился следующий переход. Текст не должен обрываться на середине ухода.
4. Не повторять прошлые версии; стиль Apple можно, но проще. Плавность, размытие движения и физику похвалили — оставить.
5. Насыщеннее, активнее, подробнее, эпичнее; музыка должна «качать», повествование — уверенное.
6. Упаковки в высоком качестве вырезаны криво — вырезать заново аккуратно.
